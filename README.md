# DevFest 2026 - GDG Kolkata

A responsive event website for DevFest 2026, presented by Google Developer Groups Kolkata.

## Highlights

- Responsive navigation with mobile menu support
- Event hero section with RSVP call to action
- Event overview, schedule, speakers, venue, and FAQ sections
- Google-inspired color palette and typography
- Local GDG logo asset with hosted event imagery

## Project Files

| File | Description |
| --- | --- |
| `index.html` | GitHub Pages entry point that opens the DevFest page |
| `devfest2026.html` | Complete static website and page layout |
| `gdg-logo-removebg-preview.png` | GDG logo used by the page |

## Run Locally

No build tools or package installation are required.

1. Clone the repository:

   ```bash
   git clone https://github.com/Subhadip258/GDGdevfest2026.git
   cd GDGdevfest2026
   ```

2. Open `index.html` in a browser.

For a local development server, run:

```bash
python -m http.server 8000
```

## External Resources

The page loads Tailwind CSS, Google Fonts, Font Awesome, and event imagery from external CDNs. An internet connection is required for those resources to display correctly.
